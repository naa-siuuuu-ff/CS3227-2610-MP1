**Stage 1: Planning**

This is the stage at the start where things can go really wrong. There is a choice to be lazy, and completely
outsource the creative process and choice of coming up with an app idea to the LLM, it saves energy, and the potential 
pain of coming up with an app idea yourself, and finding out later that it has already been made. However, taking this path
can cause big problems in the development process, one of them being burnout, due to making a soulless appplication that you have no connection to.

However, there is another issue, especially for a less experienced developer like me, where given the constraints, I do not know
if an idea is feasible. So I decided to come up with an idea myself, and make something that I would want to use or be happy to
have made, but let the LLM fine tune the idea and set constraints to ensure that they are withing the projects' scope and limitation.

I decided to make a note taking app, and the LLM helped me land on a markdown editor suitable for javaFX. I initally wanted certain functionality like 
drag and drop, but the LLM warned me against that, given the time limitations.

Then I planned the architechture of the application, and cross checked the one generated by Gemini with Claude, which improved it further.
After that, I paused to prompt the LLM to deeply explain to me the chosen architetchture, and how it would work when everything is completed, before starting to write code.

I also made a rough plan, which is to make a MVP, then slowly add features and make everything look nicer.
